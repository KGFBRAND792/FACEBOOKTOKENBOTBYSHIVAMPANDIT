# ⚡ Auto Typer GUI Utility

## 1. जरूरी लाइब्रेरी (Requirements)
इस स्क्रिप्ट को चलाने के लिए Python में 2 जरूरी लाइब्रेरी होनी चाहिए:
```bash
pip install pyautogui pyperclip
```
*(Tkinter Python के साथ पहले से आता है)*

## 2. स्क्रिप्ट कैसे रन करें?
कमांड प्रॉम्प्ट (CMD) या टर्मिनल में जाएँ और यह कमांड चलाएँ:
```bash
python auto_typer.py
```

## 3. कैसे इस्तेमाल करें?
1. **Browse File (.txt)** बटन दबाकर अपनी कोई भी टेक्स्ट फाइल लोड करें (या सीधे बॉक्स में लिख दें)।
2. **Start Delay:** डिफ़ॉल्ट 5 सेकंड है (ताकि आपको Notepad/Word/Browser में क्लिक करने का समय मिले)।
3. **Speed:** टाइपिंग की स्पीड सेट करें (डिफ़ॉल्ट: 0.03 सेकंड प्रति अक्षर)।
4. **Start Auto-Typing** दबाएं और 5 सेकंड के अंदर उस सॉफ्टवेयर/वेबसाइट पर क्लिक कर दें जहाँ टाइप करवाना है।
5. **Emergency Stop:** माउस कर्सर को अपनी स्क्रीन के बिल्कुल टॉप-लेफ्ट कोने (Top-Left corner) में ले जाएं।
